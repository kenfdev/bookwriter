# 日本語の本 — PDF 出力サンプル

この文章は Bookwriter の日本語 PDF を確認するために新しく書きました。ひらがな、カタカナ、漢字を読みやすく表示し、文章を選択してコピーできます。

## 見出しと本文の確認

**太字の日本語**と通常の文字を比べます。English words と日本語を同じ行に並べても、文字の幅に合わせて折り返します。*日本語の強調は正体です。Latin italics remain italic.*

「春の朝、川辺を歩く。」という短い文章を書きました。『小さな橋』を渡ると、遠くに山が見えます。数字は 0123456789、全角文字はＡＢＣ１２３、半角カナはｶﾀｶﾅです。分解された濁点も確認します：が、ぱ。

- 箇条書きの一行目です。日本語と Latin text を組み合わせます。
- 二行目には、句読点（丸括弧）と「かぎ括弧」を含めます。

> 引用文でも文字が欠けず、右側の余白を守ります。

インラインコード `const 名前 = "東京";` を本文中に置きます。脚注も確認します。[^note]

```ts
// 日本語のコメントと英語の変数名
const 名前 = "東京";
const greeting = "こんにちは、世界。";
console.log(名前, greeting);
```
